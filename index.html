geefam backups

A personal backup tool for one home server.

geefam backups copies the data on Josh Gee's home server ("geefam") to his own Google Drive every night, so it survives a failed disk, a fire or a theft. It is not a product or service, and it has no other users.

Everything is encrypted on the home server before it is uploaded, so Google stores only unreadable data. The tool can see and change only the files it creates in Drive; the rest of the Drive is out of its reach.
