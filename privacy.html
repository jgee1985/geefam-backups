Privacy policy

geefam backups. Last updated 7 October 2026.

Who uses it

geefam backups is a personal, non-commercial tool. Its only user is its developer, Josh Gee, who uses it to back up his own home server to his own Google Drive.

What Google data it accesses

It asks Google for one permission, drive.file. That lets it see and change only the files and folders it creates itself in the signed-in Google Drive. It cannot see, read or change any other file in that Drive.

How that data is used

The tool uploads its own backup files and, to check that backups can be restored, downloads them again. The contents are encrypted on the home server before upload, so the files stored in Google Drive cannot be read without a key that never leaves the owner's control.

Sharing

No data is sold, shared with or transferred to anyone. There are no analytics, no advertising and no third parties.

Retention

Backups stay in the owner's own Drive. The tool keeps 30 daily and 12 monthly copies and deletes older ones automatically.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions. Deleting the geefam-backups folder from Drive removes all backups.

Google API Services User Data Policy

geefam backups' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions go to github.com/jgee1985, or as an issue on this site's repository.
